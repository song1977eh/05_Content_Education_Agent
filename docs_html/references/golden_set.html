시스템 평가 — 골든셋 (references/golden_set.md)

참조 우선순위 6번. 이 에이전트가 실제로 신뢰할 만한지 검증하는 평가표. 상태: 검증 미완료 (가상 데이터 기반) — 실제 답사/세미나 사례가 쌓이면 아래 가상 예시를 실제 사례로 교체한다.

평가 축 (3축)

축 질문
안정성 같은 폴더를 다시 넣어도 같은 분류·같은 승인요청이 나오는가
합리성 콘텐츠 유형 매핑이 content_conversion_rules.md 기준과 일치하는가
사용성 안내 레이어(Phase1~4)가 필요한 정보를 다 받아내는가, 승인 요청이 사람이 판단하기 충분히 구체적인가

가상 예시 (유형별 최소 1개, 실사례로 교체 예정)

예시 1 — 실무활용자료 (답사)

  • 입력: 가상의 현장답사 폴더(사진 5장, 메모 1건)
  • 기대 결과: 마스킹 통과 → 분석완료 → 실무활용자료 초안(체크리스트형) 생성
  • 채점: 안정성 [ ] 합리성 [ ] 사용성 [ ]

예시 2 — 강의자료 (세미나)

  • 입력: 가상의 세미나 자료 폴더(PPT 1건, 메모)
  • 기대 결과: 사실/의견 분리 → 강의자료 초안(개요+슬라이드 목차)
  • 채점: 안정성 [ ] 합리성 [ ] 사용성 [ ]

예시 3 — 판매 가능한 지식 콘텐츠 (복수 폴더 종합)

  • 입력: 가상의 답사 2건 + 세미나 1건 종합
  • 기대 결과: 개별 폴더로는 부족 판정 → 종합 후 판매 콘텐츠 초안
  • 채점: 안정성 [ ] 합리성 [ ] 사용성 [ ]

예시 4 — 해민건축 콘텐츠 (전시)

  • 입력: 가상의 전시 관람 폴더(사진 다수)
  • 기대 결과: 저작권 승인 필요(타인 촬영 사진 포함 가정) → 승인 요청 발생 → 승인 후 콘텐츠 초안
  • 채점: 안정성 [ ] 합리성 [ ] 사용성 [ ]
