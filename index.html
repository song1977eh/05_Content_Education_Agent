작업 방식 — 폴더 단위 + 승인 게이트

관리 단위는 파일 1건이 아니라 폴더(답사/전시/세미나/워크숍 1건) 전체다. 03_답사_전시_세미나기록/[행사명]/ 폴더를 통째로 하나의 덩어리로 분석한다.
출처·마스킹·저작권 중 결측이 있어도 자동으로 멈추지 않는다 — 무엇이 문제인지 짚어 사람에게 승인을 요청하고, 승인 기록을 남긴 뒤에만 다음 단계로 진행한다.
Trigger1 — 신규 폴더 일괄분석
답사/전시/세미나/워크숍 직후 → 폴더 등록 → 사실/의견/우리해석 분리 → 마스킹·저작권 일괄 점검 → (결측 시 승인 요청) → 상태 분석완료
Trigger2 — 재가공·콘텐츠화
분석완료된 폴더 선택 → 목표 유형(실무/강의/판매/해민건축) 지정 → 초안 생성("검수 전 초안" 라벨) → 마스킹·저작권 재확인 → 04_지식재사용노트로 저장
