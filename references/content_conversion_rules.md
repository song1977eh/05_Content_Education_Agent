# 4종 콘텐츠 변환 규칙 (references/content_conversion_rules.md)

> 참조 우선순위 3번. 분석 완료된 폴더(덩어리)를 4종 콘텐츠 중 하나 이상으로 변환하는 기준.

## 1. 4종 콘텐츠 개요

| 유형 | 목적 | 대상 독자 | 톤 | 저작권 민감도 |
|---|---|---|---|---|
| 1. 실무활용자료 | 해민건축 실무에 바로 활용 | 내부(해민건축 직원) | 실무적, 체크리스트형 | 낮음 (내부용) |
| 2. 강의자료 | 협회 특강·사내 교육 | 외부 청중(건축사·업계) | 설명적, 사례 중심 | 중간 (발표 슬라이드는 재구성 필수) |
| 3. 판매 가능한 지식 콘텐츠 | 유료 콘텐츠/강의/전자책 | 일반 대중 또는 전문가 | 완성도 높은 정제된 문체 | 높음 (원문 재유포 절대 금지, 완전 재구성) |
| 4. 해민건축 콘텐츠 | 브랜드 블로그/SNS | 잠재 고객 | 친근하고 신뢰감 있는 톤 | 중간 (이미지 저작권 특히 주의) |

## 2. 변환 매핑 기준

폴더 분석 결과(사실/의견/우리해석)를 아래 기준으로 각 유형에 매핑한다.

- **실무활용자료**: "우리 해석" 비중이 높고, 구체적 수치·체크리스트·절차가 있는 내용
- **강의자료**: "사실+의견"이 균형 있고, 사례로 설명하기 좋은 스토리가 있는 내용
- **판매 가능한 지식 콘텐츠**: 여러 폴더(여러 답사/세미나)를 종합해야 나올 수 있는, 독자적 정리·통찰이 담긴 내용. 단일 폴더만으로는 부족한 경우가 많음 — 여러 건이 누적된 뒤 재검토.
- **해민건축 콘텐츠**: 시각 자료(사진)가 좋고, 이야기로 풀기 쉬운 내용

## 3. 유형별 산출 포맷

| 유형 | 산출 포맷 | 저장 위치 |
|---|---|---|
| 실무활용자료 | md 체크리스트 / 요약노트 | `04_지식재사용노트/실무자료/` |
| 강의자료 | md 개요 + 슬라이드 목차 초안 | `04_지식재사용노트/강의자료/` |
| 판매 콘텐츠 | md 초안(제목/목차/본문 초안) | `04_지식재사용노트/판매콘텐츠/` |
| 해민건축 콘텐츠 | md 초안(제목/본문/추천 이미지 설명) | `04_지식재사용노트/해민건축콘텐츠/` |

모든 초안 상단에 다음 라벨을 필수로 부착한다.

```
[검수 전 초안]
출처 폴더: 03_답사_전시_세미나기록/[행사명]/
승인 이력: source_register.md 참조
```

## 4. 저작권/브랜드 리스크 체크 (콘텐츠화 직전 재확인)

- 원문을 그대로 인용하지 않았는가 (요약·재구성했는가)
- 타인이 촬영한 사진을 무단으로 쓰지 않았는가
- 클라이언트·프로젝트 식별정보가 남아있지 않은가 (`privacy_masking_checklist.md` 재확인)

이슈가 있으면 `content_principles.md`의 승인 대기 규칙에 따라 사람에게 승인을 요청한다.
