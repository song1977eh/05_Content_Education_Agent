# 개인정보·저작권 마스킹 체크리스트 (references/privacy_masking_checklist.md)

> 참조 우선순위 4번. `content_principles.md`의 코드 게이트(`validate_content_source()`)가 참조하는 점검 기준.
> 하나라도 미확인이면 자동 차단이 아니라 **승인 요청** (Step 2 규칙).

## 1. 개인정보·식별정보

- [ ] 얼굴이 식별되는 인물 사진 — 본인/동료 외 제3자가 있으면 모자이크 또는 사용 동의 확인
- [ ] 명함, 연락처, 이메일 등이 사진/스캔에 노출되지 않았는가
- [ ] 클라이언트명·프로젝트명·주소 등 특정 프로젝트를 식별할 수 있는 정보가 남아있지 않은가
- [ ] 세미나·워크숍 참석자 명단이 그대로 포함되지 않았는가

## 2. 저작권·2차 사용

- [ ] 강사·발표자의 슬라이드/자료를 원문 그대로 재유포하지 않는가 (요약·재구성 여부)
- [ ] 전시장 내 촬영 금지 구역 사진이 섞여 있지 않은가
- [ ] 타인이 촬영한 사진(공식 사진팀, 타 참가자 공유분 등)을 무단으로 쓰지 않는가
- [ ] 출처 표기가 필요한 자료에 출처가 표기되어 있는가

## 3. 판정

- 모두 통과 → `분석완료` 단계로 진행
- 하나라도 미확인/불명확 → `content_principles.md` §5 규칙에 따라 사람에게 승인 요청, 승인 시 `source_register.md`에 기록 후 진행

## 4. 마스킹 처리 방법 메모

- 사진: 모자이크/크롭 후 저장, 원본은 로컬 GD에만 두고 콘텐츠 초안에는 마스킹본만 사용
- 텍스트: 클라이언트명 등은 "OO 프로젝트", "OO동" 식으로 일반화
