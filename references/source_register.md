# 출처·승인 등록대장 (references/source_register.md)

> 참조 우선순위 5번. 폴더(행사) 단위로 등록하는 대장. `orchestrator.md`의 상태값과 1:1로 연결된다.
> 새 폴더를 등록할 때마다 아래 표에 행을 추가한다.

## 등록 대장

| 폴더명 | 유형 | 날짜 | 마스킹 확인 | 저작권 확인 | 승인 이력(결측 있었을 경우) | 현재 상태 |
|---|---|---|---|---|---|---|
| (예시) 2026-09-15_답사_판교테크노밸리 | 답사 | 2026-09-15 | 완료 | 완료 | - | 분석완료 |

> 실제 사용 시 이 예시 행은 삭제하고, 등록되는 폴더마다 새 행을 추가한다.

## 승인 이력 기록 형식

문제(결측/불명확)가 있었는데도 사람이 진행을 승인한 경우, 아래 형식으로 기록한다.

```
[날짜] / [폴더명] / [결측 항목] / [승인자] / [승인 사유 또는 코멘트]
```

예: `2026-09-16 / 2026-09-15_답사_판교테크노밸리 / 저작권 출처 불명확 / song1977eh / 개인 촬영분이라 문제없음, 진행 승인`

## 콘텐츠화 이력 (선택, 폴더당 여러 유형 가능)

| 폴더명 | 콘텐츠 유형 | 초안 완료일 | 검수 상태 |
|---|---|---|---|
| (예시) 2026-09-15_답사_판교테크노밸리 | 실무활용자료 | 2026-09-17 | 검수대기 |
