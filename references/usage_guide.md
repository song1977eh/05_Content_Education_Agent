# 사용설명서 (references/usage_guide.md)

> 이 문서는 05_Content_Education_Agent를 실제로 어떻게 쓰는지 설명한다. 설계 배경은 [agent_buildup_process.md](../agent_buildup_process.md), 세부 규칙은 [content_principles.md](content_principles.md) 참조.

## 이 에이전트로 무엇을 하나

답사·전시·세미나·워크숍을 다녀온 뒤, 그 기록을 **실무자료 / 강의자료 / 판매 가능한 지식 콘텐츠 / 해민건축 콘텐츠** 4종 중 필요한 것으로 정리해준다.

## 1. 답사/세미나 다녀온 직후 — Trigger1 (신규 폴더 등록)

1. GD `03_답사_전시_세미나기록/`에 `YYYY-MM-DD_유형_장소또는주제/` 이름으로 폴더를 만들고, 사진·메모·PDF 등 원본을 그대로 넣는다.
2. Claude Code 세션에서 "새 답사 자료 등록해줘, 폴더는 [폴더명]" 이라고 말한다.
3. 에이전트가 폴더 전체를 훑어 사실/의견/우리해석을 정리하고, 마스킹·저작권 문제가 있으면 구체적으로 물어본다.
4. 문제가 있어도 "괜찮다, 이대로 진행" 또는 "이 조건으로 진행"이라고 답하면 승인 기록을 남기고 계속 진행한다. 문제를 해결하기 전까지 보류하고 싶으면 "보류"라고 답한다.
5. 완료되면 `분석완료` 상태가 되고, `references/source_register.md`에 등록된다.

## 2. 콘텐츠로 만들고 싶을 때 — Trigger2 (재가공)

1. "[폴더명]을 [실무자료/강의자료/판매콘텐츠/해민건축콘텐츠]로 만들어줘"라고 요청한다.
2. 에이전트가 초안을 만들어 보여준다 — 항상 "검수 전 초안" 라벨이 붙어 있다.
3. 초안은 그대로 발행/판매하면 안 되고, 반드시 사람이 검수한 뒤 사용한다.
4. 하나의 폴더에서 여러 콘텐츠 유형을 동시에 만들 수 있다(예: 같은 답사에서 실무자료 + 해민건축 콘텐츠 둘 다).

## 3. 자주 묻는 질문

**Q. 아직 마스킹을 다 못했는데 먼저 정리만 해달라고 할 수 있나?**
A. 가능하다. 결측이 있어도 자동으로 막지 않고 승인을 물어본다. "일단 진행하고 나중에 마스킹 확인"이라고 답하면 그 조건이 기록된다.

**Q. 새 컴퓨터(집/사무실)에서 이어서 하려면?**
A. `git pull`로 로컬을 최신화한 뒤 "지금까지 뭐가 진행 중이었지?"라고 물으면 `data/state.json`을 읽어 알려준다.

**Q. 이 문서(시스템 md 파일들)를 웹에서 편하게 보고 싶다.**
A. `scripts/build_site.py`를 실행하면 모든 md 문서가 html로 변환되고 `docs_html/index.html`에서 한눈에 볼 수 있다. GD `05_Content_Education_Agent/` 폴더에도 같은 내용이 게시된다. md 파일을 수정한 뒤에는 이 스크립트를 다시 실행해야 반영된다(자동 감시는 아님).

## 4. 하지 않는 것

- 최종 발행·판매 등록 (사람이 함)
- 법률·세무 자문
- 원문 그대로 재유포
